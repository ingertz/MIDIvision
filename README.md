# MIDIvision

밴드 MIDI(또는 악보)를 드럼 / 기타 / 베이스 / 건반 파트별 MIDI로 나눠 주는 프로그램입니다.
스타 레조넌스 인게임 연주용으로, 드럼은 인게임 건반 키에 맞게 음을 옮겨 줍니다.

## 실행

`Convert_Midi.bat`을 더블클릭하면 됩니다. (Python 필요, 패키지는 처음 실행할 때 자동 설치)

- 창에 파일이나 폴더를 끌어다 놓거나, 파일 선택 버튼으로 고릅니다.
- bat 파일 위에 파일을 바로 끌어다 놓아도 됩니다.
- 결과는 원본과 같은 폴더에 `(Drum)__곡명.mid`, `(Guitar)__곡명.mid`, `(Bass)__곡명.mid`, `(Keyboard)__곡명.mid`로 저장됩니다.
  밑줄 두 개 사이에 번호를 넣어 `(Drum)_01_곡명.mid`처럼 정리할 수 있습니다.
- 이름이 `(Drum)_`처럼 악기로 시작하는 파일은 결과 파일로 보고, 폴더를 통째로 넣었을 때 다시 분리하지 않습니다.

exe로 만들고 싶으면 `build_exe.bat`을 실행합니다. (`dist\Convert_Midi.exe`)

## 입력 파일

| 형식 | 비고 |
| --- | --- |
| `.mid` `.midi` | 가장 정확함 |
| `.mxl` `.musicxml` | 악보 프로그램에서 내보낸 MusicXML |
| `.pdf` | [Audiveris](https://github.com/Audiveris/audiveris/releases)(무료 악보 인식 프로그램) 설치 필요 |

## 파트 분류

- **드럼**: 채널 10 / XG 드럼 킷. 인게임 키로 음 이동
  - 킥 F4 `F` · 스네어 C5 `Q` · 하이햇 D4 `S` · 오픈 하이햇 G5 `T`
  - 미드 탐 D5 `W` · 하이 탐 E5 `E` · 플로어 탐 A4 `H` · 크래시 F5 `R` · 라이드 A5 `Y`
- **기타 / 베이스**: 트랙 이름 또는 악기 번호로 판별, 원음 유지
- **건반**: 나머지 전부 (보컬 멜로디, 피아노, 신스, 관현악 등), 원음 유지

## 옵션

- **채널 0 통일**: 인게임에서 악기를 인식하도록 모든 음을 채널 1로 모음 (권장)
- **화음/트랙 간소화**: 패드·효과음을 빼고 동시에 누르는 음 수를 제한 (건반 3 / 기타 3 / 베이스 1, 멜로디 우선)

## PDF 악보 관련 주의

PDF는 악보 그림을 인식해서 음표로 바꾸는 방식이라 MIDI만큼 정확하지 않습니다.

- 악보 프로그램에서 뽑은 깨끗한 PDF가 잘 되고, 스캔본·사진은 오류가 많습니다.
- 비밀번호가 걸린 PDF는 읽지 못합니다. 비밀번호를 푼 PDF를 넣어야 합니다.
- TAB 보표는 읽지 않습니다. 오선보가 같이 있어야 합니다.
- 하이햇·심벌(X 모양 음표)은 Audiveris가 못 읽어서 이 프로그램이 페이지 그림에서 직접 찾습니다.
  드럼 보표(맨 아래 보표) 주변의 X 모양만 찾고, 오픈 하이햇(○ 표시)은 구분하지 못해 닫힌 하이햇으로 나옵니다.
- 리듬을 잘못 읽은 마디는 음표의 가로 위치로 바로잡습니다. 같은 박의 음표는 모든 파트에서 같은 가로 위치에
  놓이므로, 리듬이 맞게 읽힌 파트를 기준 삼아 나머지 파트의 음이 시작하는 때를 다시 정합니다.
  음의 길이까지는 고치지 못합니다.
- 파트는 보표 모양으로 추정합니다 (일본식 밴드스코어 기준). 조표가 있는 낮은음자리표 한 단 = 베이스,
  그 아래 = 드럼, 바로 아래에 TAB이 붙은 파트 = 기타, 나머지 = 건반. 악보 구성이 다르면 잘못 분류될 수 있습니다.
- 박자표를 못 읽으면 가장 흔한 마디 길이(보통 4박)로 모든 마디를 맞춥니다. 중간에 박자가 바뀌는 곡은 어긋납니다.
- 템포(악보 첫 줄의 ♩= 숫자)를 자동으로 읽으려면 Audiveris에 영어 글자 인식 데이터가 있어야 합니다.
  Audiveris를 실행해서 `Tools → Languages`에서 `eng`를 체크하면 설치됩니다. 템포를 읽는 데 40초쯤 더 걸립니다.
  못 읽으면 120으로 저장되니, 화면의 "악보(PDF) 템포 BPM" 칸에 직접 적으세요. 칸에 적은 값이 항상 우선합니다.
- 도돌이표와 1번·2번 괄호는 풀어서 연주하지만 D.S. / D.C. / Coda는 따라가지 않습니다.
- 1번 괄호는 선이 짧게 그어져 있어도 다음 도돌이표까지 이어지는 것으로 봅니다. 괄호는 맨 위 보표에 있는 것만 인정합니다.
- 시작 도돌이표와 짝이 맞지 않는 도돌이표는 무시합니다.
- "2×"(두 번째에만 연주), "1.のみ" 같은 파트별 표시는 구분하지 못해서 그 음들은 매번 연주됩니다.
- 인식에 실패한 페이지(표지, 가사 페이지 등)는 건너뛰고 로그에 페이지 번호를 표시합니다. 그만큼 곡이 짧아집니다.
- 보표가 작은 밴드스코어를 제대로 읽기 위해 고해상도(450dpi)로 읽습니다. 쪽들을 몇 묶음으로 나눠
  Audiveris를 여러 개(최대 6개) 동시에 띄우며, 20쪽에 7분쯤 걸립니다. 그동안 CPU와 메모리를 많이 씁니다.
- 고해상도에서 Audiveris가 오류를 내는 쪽은 기본 해상도로 한 번 더 읽습니다.

## 파일 구성

- `Convert_Midi.py` — 악기 판별 / 분리 / 드럼 매핑 (명령줄로도 실행 가능, `--analyze 파일`로 트랙 판별 결과 확인)
- `Convert_Score.py` — PDF / MusicXML → MIDI 변환
- `Convert_Pages.py` — Audiveris 페이지 데이터에서 X 음표와 괄호 위치 읽기
- `Convert_Midi_GUI.py` — 화면
- `Convert_Midi.bat` — 실행
- `build_exe.bat` — exe 빌드
