# MIDIvision

밴드 MIDI(또는 악보)를 드럼 / 기타 / 베이스 / 건반 파트별 MIDI로 나눠 주는 프로그램입니다.
스타 레조넌스 인게임 연주용으로, 드럼은 인게임 건반 키에 맞게 음을 옮겨 줍니다.

## 실행

`Convert_Midi.bat`을 더블클릭하면 됩니다. (Python 필요, 패키지는 처음 실행할 때 자동 설치)

- 창에 파일이나 폴더를 끌어다 놓거나, 파일 선택 버튼으로 고릅니다.
- bat 파일 위에 파일을 바로 끌어다 놓아도 됩니다.
- 결과는 원본과 같은 폴더에 `(Drum)__곡명.mid`, `(Guitar)__곡명.mid`, `(Bass)__곡명.mid`, `(Keyboard)__곡명.mid`로 저장됩니다.
  밑줄 두 개 사이에 번호를 넣어 `(Drum)_01_곡명.mid`처럼 정리할 수 있습니다.
- 이름이 `(Drum)_`처럼 악기로 시작하는 파일은 결과 파일로 보고, 폴더를 통째로 넣었을 때 다시 분리하지 않습니다.

exe로 만들고 싶으면 `build_exe.bat`을 실행합니다. (`dist\Convert_Midi.exe`)

## 입력 파일

| 형식 | 비고 |
| --- | --- |
| `.mid` `.midi` | 가장 정확함 |
| `.mxl` `.musicxml` | 악보 프로그램에서 내보낸 MusicXML |
| `.pdf` | 악보 프로그램에서 만든 PDF는 바로 읽음. 스캔본은 [Audiveris](https://github.com/Audiveris/audiveris/releases) 설치 필요 |

## 파트 분류

- **드럼**: 채널 10 / XG 드럼 킷. 인게임 키로 음 이동
  - 킥 F4 `F` · 스네어 C5 `Q` · 하이햇 D4 `S` · 오픈 하이햇 G5 `T`
  - 미드 탐 D5 `W` · 하이 탐 E5 `E` · 플로어 탐 A4 `H` · 크래시 F5 `R` · 라이드 A5 `Y`
- **기타 / 베이스**: 트랙 이름 또는 악기 번호로 판별, 원음 유지
- **건반**: 나머지 전부 (보컬 멜로디, 피아노, 신스, 관현악 등), 원음 유지

## 옵션

- **채널 0 통일**: 인게임에서 악기를 인식하도록 모든 음을 채널 1로 모음 (권장)
- **화음/트랙 간소화**: 패드·효과음을 빼고 동시에 누르는 음 수를 제한 (건반 3 / 기타 3 / 베이스 1, 멜로디 우선)

## PDF 악보

PDF는 두 가지 방식으로 읽습니다. 어느 쪽인지는 자동으로 고릅니다.

### 1. 도형으로 된 PDF (악보 프로그램에서 만든 것)

악보 사이트에서 받은 PDF는 대부분 그림이 아니라 도형 데이터입니다. 이 경우 음표·쉼표·임시표가 어느 좌표에
있는지를 그대로 읽으므로 정확하고, 20쪽을 몇 초에 읽습니다. Audiveris가 없어도 됩니다.

- 읽는 것: 모든 5선 보표의 음높이와 리듬, 점음표, 셋잇단음표, 조표와 조바뀜, 임시표(겹내림표 포함),
  붙임줄, 8va / 8vb, 드럼의 X 모양 음표(하이햇·심벌)와 오픈 하이햇(○), 마디 반복 기호(%)
- 곡의 진행: 도돌이표, 1번·2번 괄호, D.S.(D.C.) al Coda 를 풀어서 실제 연주 순서대로 만듭니다.
  세뇨로 돌아간 뒤에는 도돌이를 하지 않고 To Coda 에서 코다로 건너뜁니다.
- "2×": 한 마디를 두 가지로 적은 곳(큰 괄호로 묶고 "2×" 표시)은 첫 번째 연주 때는 괄호 밖,
  두 번째부터는 괄호 안의 음표를 칩니다.
- 기타의 리듬 표시(사선 머리)는 그 리듬으로 코드를 치는 것으로 읽습니다. 음은 바로 아래 TAB의 숫자
  (맨 윗줄 = 1번 줄, 숫자 = 프렛, 0 = 개방현)에서 가져오고, TAB에 숫자가 없으면 직전에 잡은 코드를 칩니다.
  TAB 숫자의 생김새는 베이스·기타 보표의 음표와 짝지어 그 악보 안에서 스스로 익힙니다.
- 기타와 베이스는 악보에 실제 소리보다 한 옥타브 높게 적으므로, MIDI와 같은 실제 음높이로 내보냅니다.
- 파트 분류: 6줄 TAB 바로 위 보표 = 기타, 4줄 TAB 바로 위 = 베이스, 맨 아래 보표 = 드럼, 맨 위 = 보컬,
  나머지 = 건반. TAB이 없는 악보는 전부 건반으로 들어갑니다.
- 박이 맞지 않게 읽힌 성부는 음표의 가로 위치로 바로잡습니다. 같은 박의 음표는 모든 파트에서 같은 가로
  위치에 놓이므로, 맞게 읽힌 파트를 기준 삼아 음이 시작하는 때를 다시 정합니다. 음의 길이는 고치지 못합니다.
- 기호를 알아보는 기준은 at-elise 밴드스코어의 글꼴에 맞춘 것입니다. 다른 출판사의 PDF는 기호를 못 알아봐서
  결과가 비거나 틀릴 수 있습니다.
- 읽지 않는 것: 꾸밈음, 화살표로 다음 줄까지 이어지는 8va, 15ma, D.S. al Fine 같은 다른 형태의 점프,
  박수 등 드럼 보표에 적힌 다른 타악기 표시(X 위치에 따라 라이드나 하이햇으로 들어감)

### 2. 스캔본·사진으로 된 PDF

도형이 없는 PDF는 Audiveris로 그림을 인식합니다. 훨씬 느리고(20쪽에 7분쯤) 덜 정확합니다.

- 보표가 작은 악보를 읽기 위해 450dpi로, 쪽들을 몇 묶음으로 나눠 Audiveris를 여러 개(최대 6개) 동시에
  띄웁니다. 그동안 CPU와 메모리를 많이 씁니다.
- 고해상도에서 Audiveris가 오류를 내는 쪽은 기본 해상도로 한 번 더 읽고, 그래도 안 되는 쪽(표지, 가사 등)은
  건너뛰고 로그에 쪽 번호를 표시합니다.
- 하이햇·심벌(X 모양 음표)은 Audiveris가 못 읽어서 페이지 그림에서 따로 찾습니다. 오픈 하이햇은 구분하지 못합니다.
- TAB 보표는 읽지 않습니다. 파트는 보표 모양으로 추정합니다.

### 공통

- 비밀번호가 걸린 PDF는 읽지 못합니다. 비밀번호를 푼 PDF를 넣어야 합니다.
- 템포(악보 첫 줄의 ♩= 숫자)는 Audiveris와 영어 글자 인식 데이터가 설치되어 있으면 자동으로 읽습니다
  (Audiveris 메뉴 `Tools → Languages`에서 `eng` 체크, 40초쯤 걸림). 없거나 못 읽으면 120으로 저장되니
  화면의 "악보(PDF) 템포 BPM" 칸에 직접 적으세요. 칸에 적은 값이 항상 우선합니다.
- 1번 괄호는 선이 짧게 그어져 있어도 다음 도돌이표까지 이어지는 것으로 봅니다.
- 시작 도돌이표와 짝이 맞지 않는 도돌이표는 무시합니다.

## 파일 구성

- `Convert_Midi.py` — 악기 판별 / 분리 / 드럼 매핑 (명령줄로도 실행 가능, `--analyze 파일`로 트랙 판별 결과 확인)
- `Convert_Score.py` — PDF / MusicXML → MIDI 변환
- `Convert_Vector.py` — 도형으로 된 PDF에서 악보 직접 읽기
- `Convert_Pages.py` — (스캔본용) Audiveris 페이지 데이터에서 X 음표와 괄호 위치 읽기
- `Convert_Midi_GUI.py` — 화면
- `Convert_Midi.bat` — 실행
- `build_exe.bat` — exe 빌드
