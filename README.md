# MIDIvision

밴드 MIDI(또는 악보)를 드럼 / 기타 / 베이스 / 건반 파트별 MIDI로 나눠 주는 프로그램입니다.
스타 레조넌스 인게임 연주용으로, 드럼은 인게임 건반 키에 맞게 음을 옮겨 줍니다.

## 실행

`Convert_Midi.bat`을 더블클릭하면 됩니다. (Python 필요, 패키지는 처음 실행할 때 자동 설치)

- 창에 파일이나 폴더를 끌어다 놓거나, 파일 선택 버튼으로 고릅니다.
- bat 파일 위에 파일을 바로 끌어다 놓아도 됩니다.
- 결과는 원본과 같은 폴더에 `곡 (Drum).mid`, `곡 (Guitar).mid`, `곡 (Bass).mid`, `곡 (Keyboard).mid`로 저장됩니다.

exe로 만들고 싶으면 `build_exe.bat`을 실행합니다. (`dist\Convert_Midi.exe`)

## 입력 파일

| 형식 | 비고 |
| --- | --- |
| `.mid` `.midi` | 가장 정확함 |
| `.mxl` `.musicxml` | 악보 프로그램에서 내보낸 MusicXML |
| `.pdf` | [Audiveris](https://github.com/Audiveris/audiveris/releases)(무료 악보 인식 프로그램) 설치 필요 |

## 파트 분류

- **드럼**: 채널 10 / XG 드럼 킷. 인게임 키로 음 이동
  - 킥 F4 `F` · 스네어 C5 `Q` · 하이햇 D4 `S` · 오픈 하이햇 G5 `T`
  - 미드 탐 D5 `W` · 하이 탐 E5 `E` · 플로어 탐 A4 `H` · 크래시 F5 `R` · 라이드 A5 `Y`
- **기타 / 베이스**: 트랙 이름 또는 악기 번호로 판별, 원음 유지
- **건반**: 나머지 전부 (보컬 멜로디, 피아노, 신스, 관현악 등), 원음 유지

## 옵션

- **채널 0 통일**: 인게임에서 악기를 인식하도록 모든 음을 채널 1로 모음 (권장)
- **화음/트랙 간소화**: 패드·효과음을 빼고 동시에 누르는 음 수를 제한 (건반 3 / 기타 3 / 베이스 1, 멜로디 우선)

## PDF 악보 관련 주의

PDF는 악보 그림을 인식해서 음표로 바꾸는 방식이라 MIDI만큼 정확하지 않습니다.

- 악보 프로그램에서 뽑은 깨끗한 PDF가 잘 되고, 스캔본·사진은 오류가 많습니다.
- TAB 보표는 읽지 않습니다. 오선보가 같이 있어야 합니다.
- 파트 이름("Gt." 등)이 인식되지 않으면 기타가 건반 쪽으로 들어갈 수 있습니다.
- 템포를 못 읽으면 120 BPM으로 나옵니다.
- 도돌이표와 1번·2번 괄호는 풀어서 연주하지만 D.S. / D.C. / Coda는 따라가지 않습니다.
- 인식에 몇 분 걸릴 수 있습니다.

## 파일 구성

- `Convert_Midi.py` — 악기 판별 / 분리 / 드럼 매핑 (명령줄로도 실행 가능, `--analyze 파일`로 트랙 판별 결과 확인)
- `Convert_Score.py` — PDF / MusicXML → MIDI 변환
- `Convert_Midi_GUI.py` — 화면
- `Convert_Midi.bat` — 실행
- `build_exe.bat` — exe 빌드
